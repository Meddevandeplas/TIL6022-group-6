## 1. Overview
This project investigates to what extent age-specific policy interventions have influenced travel purposes and transport mode choice in the Netherlands between 1999 and 2025. First, the overall development of transport mode choice of the Dutch population is analysed. Then, three interventions aimed at specific age groups are studied by comparing the travel behaviour of the affected age group before and after the intervention.


## 2. Repository Content:
- Data_age_research: containing the CBS dataset used in the analysis.
- Output: containing all figures used in the report.
- Code: containing the Python code for the analysis of each sub-question.
- End_report_group6.ipynb: the main report notebook.
- End_report_group6.html: HTML export of the main report.
- README: file with instructions.


## 3. Data Sources
All analyses are based on one publicly available dataset, referred to in the report as Dataset 1 or 84755NED. It is stored in the `/Data_age_research/` directory.

| Category | Source |
|----------|--------|
| Average number of trips per person per day by transport mode, travel purpose and age group, 1999–2025 (Dataset 1, table 84755NED) | [CBS StatLine – Mobility trend figures](https://opendata.cbs.nl/statline/#/CBS/nl/dataset/84755NED) |

**Directory structure:**
`/Data_age_research/`contains the following dataset:
- 1_Mobility_trends_by_trip_(84755NED)_complete
- 2_Population_by_sex_age_and_marital_status_(7461bev)
- 3_Mobility_per_person_by_personal_characteristics_(84709NED)
- 4_Labour_participation_key_figures_(85264NED)
- Mobility_trends_per_trips (84755NED)_50+_worktrips

To download the dataset again, export table 84755NED from CBS StatLine as a CSV file with all transport modes, travel purposes and age groups selected, and save it in `/Data_age_research/` under the same file name.

`/Output/`: figures generated by the code and loaded into the report notebook.

## 4. Reproduction Guide
### 4.1 Requirements
The following are required to reproduce the analysis:

- Python 
- Installed Python packages:
  - `pandas`
  - `numpy`
  - `matplotlib`
  - `plotly`
  - `jupyter`
- Standard Python libraries used in the code: [bijv. `os`, `pathlib`] 

### 4.2 General Setup
1. Clone the repository: `git clone https://github.com/[gebruikersnaam]/TIL6022-group-6.git`
2. Install the required packages: `pip install pandas numpy matplotlib plotly jupyter`
3. Make sure the dataset is present in `/Data_age_research/`.

Key parameters:

| Parameter | Description |
|-----------|-------------------|
| Dataset | CBS 84755NED (Dataset 1), smoothed trend figures |
| Unit | Average number of trips per person per day |
| Study area | The Netherlands |
| Study period | 1999–2025 |
| COVID-19 | Years 2020–2021 excluded from the before/after comparisons |
| Sub-question 2 | Group 70+; 2008–2013 vs 2014–2019; reference trend 2004–2013 |
| Sub-question 3 | Commute trips; 65–70 vs 60–65; 2005–2012 vs 2013–2024 |
| Sub-question 4 | Train and bus/tram/metro; 12–18 vs 18–25; baseline 2014–2016 vs 2017–2019 |


### 4.3 Execution Order of Code
To reproduce all figures and analyses in the report, run the code in the following order:
1. Run `Subquestion1.ipynb`
   - Modal split of the entire population (sub-question 1)
2. Run `Subquestion2.ipynb`
   - Car-driver trips of the 70+ group (sub-question 2)
3. Run `Subquestion3.ipynb`
   - Commute trips and the state pension age (sub-question 3)
4. Run `Subquestion4.ipynb`
   - Public transport use and the student travel product (sub-question 4)

Each file reads the data from `/Data_age_research/` and saves its figures to `/Output/`.

5. Open `End_report_group6.ipynb` in Jupyter or VS Code to read the report. The figures in the report are loaded from `/Output/`.

Following this approach ensures complete reproducibility. All figures and analyses can be easily reproduced with the provided code and datasets.
